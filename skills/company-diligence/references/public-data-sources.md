# 공공데이터 소스 레퍼런스

기업 재무·고용 리스크 검증에 사용하는 공개 데이터소스 정리.
모든 소스는 무료이며 개인이 직접 신청 가능하다.

---

## 1. 국세청 사업자등록상태조회

**가장 먼저 확인해야 할 데이터.** 사업자등록번호만 있으면 계속사업 / 휴업 / 폐업 여부를 즉시 알 수 있고,
커버리지가 사실상 전 사업자라서 스타트업에도 그대로 적용된다.

- 제공처: 공공데이터포털 (data.go.kr) - 국세청 사업자등록정보 진위확인 및 상태조회 서비스
- 비용: 무료
- 신청: data.go.kr 회원가입 후 활용신청, 개발계정은 대체로 즉시 승인
- 호출 한도: 일 단위 대량 호출 허용 (신청 시 한도 확인)
- 인증: serviceKey (URL 파라미터)

**엔드포인트**
```
POST https://api.odcloud.kr/api/nts-businessman/v1/status?serviceKey={ENCODED_KEY}
Content-Type: application/json

{"b_no": ["1234567890"]}
```

**응답 주요 필드**
| 필드 | 의미 |
|---|---|
| `b_stt` | 사업자 상태: 계속사업자 / 휴업자 / 폐업자 |
| `b_stt_cd` | 상태 코드 (01 계속사업자, 02 휴업자, 03 폐업자) |
| `tax_type` | 과세 유형 |
| `end_dt` | 폐업일 (폐업자인 경우) |
| `utcc_yn` | 단위과세전환폐업 여부 |

**판정 규칙**
- `폐업자` → 즉시 RED. 더 볼 것 없음
- `휴업자` → RED. 급여 지급 능력 없음
- 조회 결과 없음 → 사업자번호 오기 가능성. 재확인 필요
- `계속사업자` → 통과. 단 이것은 최소 요건일 뿐 재무 건전성 증명이 아님

**사업자등록번호를 모를 때**
- 채용공고 하단 사업자정보 표기
- 회사 홈페이지 하단 푸터
- 이커머스 사업자면 통신판매업 신고번호와 함께 표기
- 국민연금공단 사업장 가입 현황 (공공데이터포털) 에서 회사명으로 역검색 가능

## 2. 고용노동부 임금체불 사업주 명단 공개

"월급이 밀리지 않는가"라는 이 스킬의 원래 질문에 **가장 직접적으로 대응하는 데이터**.

- 제공처: 고용노동부 (moel.go.kr) 임금체불 사업주 명단 공개
- 근거: 근로기준법상 상습 체불 사업주 명단 공개 제도
- 공개 대상: 체불이 확정되고 일정 요건(체불 금액·횟수)을 충족한 사업주
- 확인 방법: 고용노동부 홈페이지 명단 공개 페이지 조회, 고용24 오픈API를 통한 조회 (개방 여부와 엔드포인트는 신청 시점 기준으로 확인 필요)

**중요한 해석 주의**
- 명단은 **체불이 확정되고 요건을 충족한 경우만** 등재된다. 즉 명단에 없다고 체불이 없었다는 뜻이 아니다.
- 명단 등재는 강한 양성 신호(있으면 확실히 나쁨)이지만, 부재는 약한 음성 신호(없어도 안심 불가)다.
- 따라서 명단 조회 결과가 없으면 반드시 뉴스·커뮤니티 검색으로 보완한다.

**보완 검색 쿼리**
```
"{기업명}" 임금체불
"{기업명}" 급여 지연
"{기업명}" 월급 밀
"{기업명}" 체불 진정
"{기업명}" 노동청
```

## 3. DART OpenAPI (전자공시시스템)

- 제공처: 금융감독원 opendart.fss.or.kr
- 비용: 무료
- 신청: 회원가입 후 인증키 신청, 개인은 즉시 발급 (40자리 키)
- 법인 신청은 사업자등록증 제출 후 심사에 1~2일 소요
- 일일 호출 한도: 문서에 따라 10,000건 / 20,000건 표기가 갈리므로 발급 시점에 직접 확인

**커버리지 (이 스킬에서 가장 중요한 제약)**

DART 공시 의무 대상:
- 상장법인 (코스피 / 코스닥 / 코넥스)
- 외부감사 대상 법인
  - 자산총액 120억원 이상, 또는
  - 종업원 300명 이상이면서 자산총액 70억원 이상
  - (그 밖에 매출·부채 기준 조합 요건 있음. 정확한 최신 기준은 외부감사법 시행령 확인)

**결론: 시드~시리즈A 단계 스타트업, 소규모 중소기업은 DART에 아무것도 없다.**
이 스킬 사용자의 상당수가 그런 회사를 보게 되므로, DART 조회 실패는 오류가 아니라 정상 시나리오다.
"DART 미커버"로 기록하고 대체 신호 경로(SKILL.md Phase 3)로 넘어간다.

**주요 엔드포인트**
```
# 기업 고유번호 전체 목록 (zip 파일, 최초 1회 받아서 캐시)
GET https://opendart.fss.or.kr/api/corpCode.xml?crtfc_key={KEY}

# 기업 개황
GET https://opendart.fss.or.kr/api/company.json?crtfc_key={KEY}&corp_code={CORP_CODE}

# 단일회사 주요계정 (재무제표 요약)
GET https://opendart.fss.or.kr/api/fnlttSinglAcnt.json
    ?crtfc_key={KEY}&corp_code={CORP_CODE}&bsns_year={YYYY}&reprt_code=11011

# 공시 목록 (정정공시·감사보고서 탐지용)
GET https://opendart.fss.or.kr/api/list.json
    ?crtfc_key={KEY}&corp_code={CORP_CODE}&bgn_de={YYYYMMDD}&end_de={YYYYMMDD}
```

`reprt_code`: 11011 사업보고서, 11012 반기보고서, 11013 1분기, 11014 3분기

**재무 위험 신호 판정**
| 지표 | 계산 | 위험 기준 |
|---|---|---|
| 부채비율 | 부채총계 / 자본총계 x 100 | 200% 초과, 특히 전년 대비 급증 |
| 자본잠식 | 자본총계 < 0 또는 자본금 미만 | 완전자본잠식이면 RED |
| 매출 추이 | 3개년 매출액 | 2년 연속 감소 |
| 영업이익 | 3개년 영업이익 | 연속 적자 + 현금성자산 감소 동반 |
| 유동비율 | 유동자산 / 유동부채 x 100 | 100% 미만이면 단기 지급능력 경고 |

**재무제표보다 선행하는 신호 (공시 목록에서 탐지)**
- 감사의견: 적정 외 (한정 / 부적정 / 의견거절) → 즉시 RED
- 감사인 교체가 잦음
- 정정공시 반복
- 최대주주 변경 / 대표이사 잦은 교체
- 전환사채·신주인수권부사채 반복 발행 (자금 압박 신호일 수 있음)
- 소송 등의 제기 공시

## 4. 국민연금 가입 사업장 내역

**비상장 스타트업 실사에서 DART보다 실용적인 데이터소스.**
회사명만으로 조회되고, DART가 커버하지 못하는 소규모 법인도 대부분 수록된다.

- 제공처: 공공데이터포털 (국민연금공단_국민연금 가입 사업장 내역)
- 비용: 무료, 개발계정 자동 승인
- 인증: serviceKey (국세청 조회와 같은 키를 쓴다. 포털 계정당 인증키는 하나)
- 수록 범위: 가입자 3인 이상 법인사업장, 10인 이상 개인사업장
- 스크립트: `scripts/lookup_workplace.py`

**엔드포인트**
```
BASE = http://apis.data.go.kr/B552015/NpsBplcInfoInqireServiceV2

GET {BASE}/getBassInfoSearchV2          사업장 검색
    ?serviceKey={KEY}&dataType=json&wkpl_nm={회사명}&numOfRows=20&pageNo=1

GET {BASE}/getDetailInfoSearchV2        사업장 상세
    ?serviceKey={KEY}&dataType=json&seq={SEQ}

GET {BASE}/getPdAcctoSttusInfoSearchV2  기간별 인원 현황
    ?serviceKey={KEY}&dataType=json&seq={SEQ}&numOfRows=20
```

HTTPS가 아니라 HTTP만 지원한다.

**주요 응답 필드**

검색 (`getBassInfoSearchV2`)
| 필드 | 의미 |
|---|---|
| `seq` | 사업장 식별번호. 상세 조회에 사용 |
| `wkplNm` | 사업장명 |
| `bzowrRgstNo` | 사업자등록번호 **앞 6자리만** |
| `wkplRoadNmDtlAddr` | 도로명 상세주소 |
| `wkplJnngStcd` | 가입상태 (1 등록, 2 탈퇴) |
| `wkplStylDvcd` | 형태 (1 법인, 2 개인) |
| `ldongAddrMgplDgCd` | 법정동 시도 코드 |

상세 (`getDetailInfoSearchV2`)
| 필드 | 의미 |
|---|---|
| `jnngpCnt` | **가입자 수. 사실상 실제 직원 수** |
| `vldtVlKrnNm` | 업종명 |
| `adptDt` / `scsnDt` | 사업장 등록일 / 탈퇴일 |
| `crrmmNtcAmt` | 당월 고지금액 |

기간별 (`getPdAcctoSttusInfoSearchV2`)
| 필드 | 의미 |
|---|---|
| `dataCrtYm` | 자료 생성 년월 |
| `nwAcqzrCnt` | 월별 취득자 수 (입사) |
| `lssJnngpCnt` | 월별 상실자 수 (퇴사) |

**판정에 쓰는 법**
| 관측 | 의미 |
|---|---|
| `wkplJnngStcd` = 2 (탈퇴) | 폐업·휴업 강한 신호. 국세청 조회로 교차확인 |
| 회사 주장 규모 대비 `jnngpCnt` 가 크게 적음 | 공식정보 과장. "공식정보의 이면" 섹션에 기록 |
| 월별 순증감(`nwAcqzrCnt` - `lssJnngpCnt`)이 지속 마이너스 | 인력 축소 국면. 경고 신호 |
| 검색 결과 없음 | 3인 미만이거나 법인명 불일치. 규모가 매우 작다는 정보 자체가 신호 |

**평균 소득 역산 (참고용)**
국민연금 보험료율은 9%(근로자와 사업주 각 4.5%)이므로
`당월고지금액 / 가입자수 / 0.09` 로 평균 기준소득월액을 추정할 수 있다.
다만 기준소득월액에는 상한과 하한이 있어 **고소득 사업장은 크게 과소추정된다.**
연봉 추정이 아니라 급여 구간을 가늠하는 용도로만 쓴다.

**한계**
- 사업자등록번호를 앞 6자리만 주므로, 국세청 조회에 필요한 10자리는 다른 경로로 찾아야 한다
- 자료 생성 시점 기준이라 최신 상태와 며칠에서 몇 주 차이가 날 수 있다
- 3인 미만 법인은 아예 수록되지 않는다

### 참고: 탈퇴 사업장 정보

공공데이터포털에 "국민연금공단_탈퇴사업장 정보"가 별도로 개방되어 있다.
현재 스크립트는 사용하지 않지만, 이미 탈퇴한 사업장의 이력을 조회할 때 쓸 수 있다.

## 5. 기타 참고 소스

| 소스 | 용도 |
|---|---|
| 대법원 인터넷등기소 | 법인등기부등본 열람 (유료, 소액). 대표이사 변경·자본금 변동·본점 이전 이력 확인 |
| 나이스평가정보 / 이크레더블 | 기업 신용등급. 대부분 유료 |
| 중소벤처기업부 벤처확인기업 공시 | 벤처인증 유효 여부 |
| 더브이씨(thevc.kr), 혁신의숲 | 스타트업 투자 라운드 이력. 마지막 투자 시점 확인용 |
| 잡플래닛 / 블라인드 | 재직자 리뷰. 로그인 장벽으로 검색 스니펫까지만 접근 |
| 앱스토어 / 플레이스토어 | 앱 최근 업데이트일. 제품 개발 지속 여부 확인 |

## API 키 준비 체크리스트

1. **공공데이터포털 (data.go.kr)** 회원가입 후 아래 둘 다 활용신청
   - 국세청_사업자등록정보 진위확인 및 상태조회 (폐업·휴업 확인)
   - 국민연금공단_국민연금 가입 사업장 내역 (직원 수·인원 추이 확인)
   - 두 서비스가 같은 인증키를 공유한다. 키는 계정당 하나다
2. **DART (opendart.fss.or.kr)** 회원가입 → 인증키 발급 (선택, 상장사 분석 시)
3. 발급받은 키를 환경변수로 등록
   ```bash
   export ODCLOUD_SERVICE_KEY="발급받은키"
   export DART_API_KEY="발급받은키"
   ```

키가 없어도 스킬은 동작한다. 공공API 검증 단계만 건너뛰고 웹 검색 기반 분석으로 진행하며,
리포트에 "공공데이터 미검증"으로 표기한다.
처음에는 키 없이 한 번 돌려보고, 결과가 부족하다고 느낄 때 키를 발급받아 다시 돌려보면
어떤 판정 근거가 추가되는지 직접 비교할 수 있다.
