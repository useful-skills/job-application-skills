# 동명 기업 판별 절차

한국에는 같은 상호를 쓰는 법인이 매우 많다.
잘못된 법인을 분석하면 실사 결과 전체가 무의미해지므로, 이 단계는 생략할 수 없다.

---

## 왜 중요한가

- 상호는 동일 업종·동일 관할이 아니면 중복 등기가 가능하다
- "(주)토스"와 "토스 주식회사"처럼 표기만 다른 경우와, 완전히 무관한 동명 법인이 섞인다
- 지주회사와 사업회사가 유사한 이름을 쓴다 (OO홀딩스 / OO / OO코리아)
- 브랜드명과 법인명이 다른 경우가 흔하다 (서비스명으로 검색하면 운영 법인을 못 찾음)
- 채용은 유명 모회사 이름으로 하고 계약은 자회사·아웃소싱 법인과 하는 경우가 있다

**급여를 지급하는 주체는 근로계약을 맺는 법인이다.**
실사 대상은 브랜드가 아니라 그 법인이어야 한다.

---

## 판별 절차

### Step 1. 입력에서 확정 가능한지 확인

우선순위 순으로 확인한다.

| 입력 | 확정도 | 처리 |
|---|---|---|
| 사업자등록번호 | 확정 | 즉시 진행 |
| 채용공고 URL | 높음 | 공고 하단 사업자정보 추출 |
| 홈페이지 URL | 중간 | 푸터의 법인명·사업자번호 추출 |
| 기업명만 | 낮음 | Step 2로 |

### Step 2. 국민연금 사업장 조회로 후보 좁히기

회사명만 있을 때 가장 먼저 쓸 수 있는 확정 데이터다.

```bash
python3 scripts/lookup_workplace.py --search "회사명"
```

돌아오는 정보로 후보를 구분한다.

| 필드 | 판별에 쓰는 법 |
|---|---|
| 사업장명 | 정식 법인명 표기 확인 ("주식회사 OO" vs "OO 주식회사") |
| 주소 | 채용공고의 근무지와 대조 |
| 법인/개인 구분 | 공고가 법인 채용이면 개인사업장 후보 제외 |
| 등록/탈퇴 상태 | 탈퇴 사업장은 폐업·휴업 가능성 |
| 사업자등록번호 앞 6자리 | 다른 경로로 찾은 번호와 대조 검증 |

`--detail {seq}` 로 직원 수와 업종까지 보면 대부분 후보가 하나로 좁혀진다.

**주의: 이 API는 사업자등록번호 앞 6자리만 준다.**
국세청 상태 조회에 필요한 10자리 전체는 Step 3에서 따로 찾아야 한다.

검색 결과가 없다면 다음 중 하나다.
- 법인 3인 미만 또는 개인사업장 10인 미만이라 수록 대상이 아님
- 브랜드명과 등록 법인명이 다름 (푸터에서 정식 법인명을 확인해 재검색)
- 사업장이 탈퇴 처리됨

### Step 3. 사업자등록번호 10자리 추출 시도

다음 위치를 순서대로 확인한다.

1. **채용공고 하단**: 사람인·잡코리아·원티드 등은 기업 정보란에 사업자번호 또는 법인 정보를 노출
2. **홈페이지 푸터**: "사업자등록번호", "통신판매업신고번호" 표기
3. **이용약관 / 개인정보처리방침 페이지**: 사업자 정보가 법적으로 기재되는 문서
4. **앱스토어 앱 정보**: 개발자 정보란에 사업자 정보 표기

찾은 번호의 앞 6자리가 Step 2 결과와 일치하는지 대조하면 확신도가 올라간다.
10자리를 끝내 못 찾으면 국세청 조회만 건너뛰고 나머지 분석은 그대로 진행한다.

### Step 4. 후보가 여러 개면 사용자에게 확인

웹 검색으로 후보를 수집한 뒤, 각 후보를 다음 항목으로 정리해 제시한다.

```
후보 1) 주식회사 OOO
  업종: 소프트웨어 개발
  소재지: 서울 강남구
  홈페이지: example.com
  최근 활동: 2025년 시리즈A 투자 유치 기사

후보 2) OOO 주식회사
  업종: 건설자재 도소매
  소재지: 경기 화성시
  홈페이지: 없음
  최근 활동: 확인 안 됨
```

사용자가 하나를 고르면 진행한다.
채용공고 URL이 있으면 그 공고의 업종·소재지와 대조해 자동으로 좁힐 수 있다.

### Step 5. 계약 법인 확인

후보가 좁혀져도 마지막 확인이 남는다.

- 공고에 명시된 "근무지"와 "소속 법인"이 다른가
- 공고 주체가 헤드헌팅사 또는 아웃소싱 업체인가
- 대기업 브랜드 공고인데 계약 법인이 자회사인가

이 경우 **분석 대상을 계약 법인으로 전환**하고, 리포트에 다음을 명시한다.

> 이 공고의 브랜드는 A이지만 근로계약 주체는 B입니다. 급여 지급 주체는 B이므로 B를 기준으로 실사했습니다.

---

## 확정 후 기록할 식별자

실사 리포트 상단에 다음을 고정 기재한다.

```
정식 법인명:
사업자등록번호:
법인등록번호: (확보 시)
대표자:
소재지:
홈페이지:
상장 여부: 상장 / 비상장
DART 고유번호(corp_code): (해당 시)
분석 대상 확정 근거: (어떤 경로로 이 법인으로 확정했는지)
```

마지막 항목이 중요하다. 나중에 리포트를 다시 볼 때
"내가 맞는 회사를 본 게 맞나"를 검증할 수 있어야 한다.

---

## 확정 실패 시 처리

사업자번호를 못 찾고 후보도 좁혀지지 않으면, 분석을 강행하지 않는다.
대신 다음을 사용자에게 안내한다.

> 분석 대상 법인을 특정하지 못했습니다.
> 채용공고 URL을 알려주시거나, 공고 하단의 사업자등록번호를 확인해 주시면 정확한 실사가 가능합니다.
> 법인이 특정되지 않은 상태의 검색 결과는 다른 회사 정보가 섞일 수 있어 신뢰할 수 없습니다.

부정확한 리포트를 내는 것보다 못 냈다고 말하는 편이 낫다.
