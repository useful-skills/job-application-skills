# 쉬운 말로 옮기기

이 스킬을 쓰는 사람은 취업준비생이다. 회계나 공시를 배운 적이 없다고 가정한다.

리포트를 읽으려고 용어를 먼저 공부해야 한다면 그 리포트는 실패다.
**판정 로직에는 전문용어를 그대로 쓰되, 사용자에게 나가는 문장에서는 전부 풀어쓴다.**

---

## 원칙

1. **용어를 쓰고 괄호로 설명하지 않는다.** 아예 안 쓴다.
   - 나쁨: "부채비율이 250%입니다 (부채비율은 부채총계를 자본총계로 나눈 값)"
   - 좋음: "빚이 회사가 가진 자기 돈의 2.5배입니다"
2. **비율보다 사람 수와 돈으로 말한다.** "이직률 33%"보다 "직원 24명 중 1년에 8명이 나갔습니다"가 먼저 이해된다.
3. **그래서 뭐가 문제인지 한 문장 붙인다.** 숫자만 주면 판단은 여전히 사용자 몫이다.
4. **모르면 모른다고 쓴다.** 어려운 말로 얼버무리지 않는다. "확인할 수 없었습니다"가 정직하다.
5. **겁주지 않는다.** 사실을 전하되 단정하지 않는다. "망합니다"가 아니라 "이런 신호가 보입니다".

## 변환표

### 재무 상태

| 판정 로직 용어 | 사용자에게 보이는 말 |
|---|---|
| 부채비율 200% 초과 | 빚이 회사 자기 돈의 2배가 넘습니다 |
| 부채비율 전년 대비 100%p 급증 | 작년보다 빚이 크게 늘었습니다 |
| 완전자본잠식 | 가진 것을 다 팔아도 빚이 남는 상태입니다 |
| 유동비율 100% 미만 | 1년 안에 갚아야 할 돈이, 1년 안에 들어올 돈보다 많습니다 |
| 영업손실 2년 연속 | 2년째 본업에서 돈을 못 벌고 있습니다 |
| 매출 2년 연속 감소 | 2년째 매출이 줄고 있습니다 |
| 현금성자산 동반 감소 | 회사에 남은 현금도 같이 줄고 있습니다 |
| 감사의견 거절 / 부적정 | 외부 회계법인이 "이 회사 장부는 못 믿겠다"고 했습니다. 가장 나쁜 신호입니다 |
| 감사의견 한정 | 외부 회계법인이 장부 일부를 확인하지 못했다고 했습니다 |
| 감사인 교체 2년 내 2회 | 회사 장부를 봐주는 회계법인이 자주 바뀌었습니다 |
| 정정공시 반복 | 공시한 내용을 여러 번 고쳤습니다 |
| 전환사채·신주인수권부사채 반복 발행 | 나중에 주식으로 바꿔주는 조건으로 돈을 자주 빌렸습니다. 급하게 자금을 구한다는 뜻일 수 있습니다 |
| 최대주주 변경 | 회사의 주인이 바뀌었습니다 |
| DART 미커버 | 법적으로 재무제표를 공개할 의무가 없는 회사라, 공식 재무 정보를 볼 수 없습니다 |
| 외부감사 대상 아님 | 회사 규모가 작아서 외부 회계 감사를 안 받습니다 |

### 투자와 자금 (스타트업)

| 판정 로직 용어 | 사용자에게 보이는 말 |
|---|---|
| 런웨이 | 지금 있는 돈으로 몇 달을 더 버틸 수 있는지 |
| 마지막 투자 18개월 경과 + 후속 없음 | 마지막으로 투자받은 지 1년 반이 지났는데 추가 투자 소식이 없습니다 |
| 시드 / 시리즈A | 창업 초기 투자 단계입니다. 아직 회사가 자리잡는 중이라는 뜻입니다 |
| 브릿지 라운드 반복 | 다음 정식 투자 전에 급한 돈을 여러 번 빌렸습니다 |
| 다운라운드 | 회사 가치를 이전보다 낮게 쳐서 투자받았습니다 |
| 정부 R&D 과제 의존 | 제품을 팔아서가 아니라 정부 지원금으로 운영되고 있습니다 |

### 사람과 고용 (국민연금 데이터)

| 판정 로직 용어 | 사용자에게 보이는 말 |
|---|---|
| 국민연금 가입자 수 | 4대보험에 가입된 실제 직원 수입니다 |
| 연환산 이직률 33% | 직원 24명인데 1년 동안 8명이 나갔습니다. 3명 중 1명꼴입니다 |
| 취득자 / 상실자 | 입사한 사람 / 퇴사한 사람 |
| 월별 순증감 마이너스 | 들어온 사람보다 나간 사람이 많습니다 |
| 사업장 탈퇴 | 회사가 4대보험 사업장에서 빠졌습니다. 문을 닫았을 가능성이 큽니다 |
| 당월 고지금액 | 회사가 이번 달에 내야 하는 국민연금 보험료입니다 |
| 기준소득월액 추정 | 보험료를 거꾸로 계산해서 뽑은 대략의 월급 수준입니다 |
| 회사 주장 규모와 가입자 수 괴리 | 회사가 홈페이지에 적은 인원보다 실제 직원이 적습니다 |

### 사업자 상태

| 판정 로직 용어 | 사용자에게 보이는 말 |
|---|---|
| 계속사업자 | 정상적으로 영업 중인 회사입니다 |
| 휴업자 | 영업을 잠시 멈춘 상태입니다. 월급 줄 주체가 멈춰 있다는 뜻입니다 |
| 폐업자 | 이미 문을 닫은 회사입니다 |
| 임금체불 사업주 명단 등재 | 정부가 "월급을 안 준 사업주"로 공식 발표한 회사입니다 |
| 명단에서 확인되지 않음 | 명단에는 없지만, 체불이 없었다는 뜻은 아닙니다. 명단은 문제가 커진 경우만 올라갑니다 |

### 판정 등급

등급 기호를 그대로 노출하지 않는다. 아래 문장을 쓴다.

| 내부 등급 | 사용자에게 보이는 말 |
|---|---|
| RED | **지원 전에 다시 생각해보세요.** 확인된 위험 신호가 있습니다 |
| AMBER | **조심스럽게 접근하세요.** 걱정되는 신호가 몇 개 보입니다 |
| GREEN | **특별히 걱정할 신호는 안 보입니다.** 다만 안전하다는 보장은 아닙니다 |
| UNKNOWN | **판단할 정보가 부족합니다.** 정보가 없다는 것 자체를 위험으로 보세요 |

### 근거의 성격

`[확정]` 같은 기호를 리포트에 찍지 않는다. 필요하면 말로 푼다.
자세한 내용은 `evidence-grades.md` 참조.

| 내부 등급 | 사용자에게 보이는 말 |
|---|---|
| `[확정]` | (그냥 단정형으로 쓴다) "직원은 24명입니다" |
| `[계산]` | "24명 중 8명이 나갔으니 3명 중 1명꼴입니다" (숫자를 같이 보여준다) |
| `[추정]` | "~로 보입니다", "~일 가능성이 있습니다" |
| `[전언]` | "후기에 이런 얘기가 2건 있었습니다. 사실인지는 확인 못 했습니다" |
| `[미확인]` | "이건 확인하지 못했습니다" |

## 문장 다듬기 예시

리포트 한 줄이 어떻게 바뀌는지.

| 고치기 전 | 고친 뒤 |
|---|---|
| 종합 판정: AMBER. 대체 재무 신호 3개 점등 `[추정]` | 조심스럽게 접근하세요. 걱정되는 점이 세 가지 있습니다 |
| 연환산 이직률 33% `[계산]` | 직원 24명 중 최근 1년에 8명이 퇴사했습니다. 3명 중 1명꼴입니다 |
| 사업자 상태: 계속사업자 `[확정]` | 정상 영업 중인 회사입니다 |
| DART 미커버로 재무 검증 불가 `[미확인]` | 재무제표를 공개할 의무가 없는 회사라 매출이나 이익은 확인할 수 없었습니다 |
| 마지막 투자 22개월 경과 `[추정]` | 마지막 투자를 받은 지 1년 10개월이 지났는데 추가 투자 소식이 없습니다. 자금이 빠듯할 수 있습니다 |
| 1인당 고지금액 기준 평균 기준소득월액 약 320만원 `[계산]` | 보험료로 거꾸로 계산해보면 월급이 대략 320만원 안팎으로 보입니다. 정확한 값은 아니고 하한선에 가깝습니다 |

## 이 표에 없는 용어가 나오면

1. 중학생에게 설명한다고 생각하고 한 문장으로 풀어쓴다.
2. 풀어쓴 문장을 이 표에 추가한다. **이 문서는 계속 자란다.**
3. 도저히 못 풀어쓰겠으면 그 항목은 리포트에서 빼는 것을 고려한다.
   설명할 수 없는 근거는 사용자에게 쓸모가 없다.
