# 근거 등급 체계

리포트의 모든 문장에 근거 등급 라벨을 붙인다.
"추론적 해석이 아니라 객관성을 가진 근거"를 강제하기 위한 장치다.
지원자가 각 문장을 어디까지 신뢰할지, 무엇을 직접 검증해야 할지 한눈에 구분할 수 있게 한다.

---

## 5종 등급

| 등급 | 의미 | 예시 |
|---|---|---|
| `[확정]` | 공공 API 원본 기록 그대로 | 사업자 상태: 계속사업자 (국세청, 2026-07-27) |
| `[계산]` | 확정 데이터로 **스크립트가** 산출. **계산식 노출 필수** | 연환산 이직률 33% = 12개월 퇴사 8명 / 현재 가입자 24명 |
| `[추정]` | 간접 신호 기반. 반증 가능 | 마지막 투자 22개월 경과 → 런웨이 압박 가능성 |
| `[전언]` | 커뮤니티·리뷰. 출처 수 명시 | 급여 지연 언급 2건 (2025-11, 2026-02) |
| `[미확인]` | 데이터 없음 | 매출 규모: 공시 의무 대상 아님 |

---

## `[계산]` 등급이 계산식을 노출해야 하는 이유

"이직률 33%"만 표기하면 그것도 블랙박스다.
숫자 하나만 던지면 지원자는 그 값을 믿을지 말지 판단할 근거가 없다.

분자와 분모를 함께 보여줘야 지원자가 직접 검증하고 반박할 수 있다.

- 분모(가입자수)가 4명뿐이라면 그 비율은 사실상 1~2명의 이동이다. 통계적 의미가 없다.
  그래서 가입자 10명 미만이면 스크립트가 비율 산출을 아예 억제하고 실수만 낸다.
- 분모가 기간 평균이 아니라 **현재 시점 인원**이라는 것도 드러나야 한다.
  기간 중 인원이 크게 변한 사업장에서는 이 값이 왜곡되기 때문이다.
- 기간이 6개월치뿐이라 x2로 연환산했다면, 그 가정을 지원자가 알아야 한다.
- 계산식이 보이면 지원자가 면접에서 "재직 인원이 몇 명이냐"를 물어 직접 대조할 수 있다.

이것이 원본 피드백에서 요구한 **"객관성을 가진 근거"의 실질적 구현**이다.
`[계산]` 항목은 결과 숫자와 함께 반드시 `= 분자 / 분모` 형태의 산출식을 같은 문장 안에 노출한다.

**산술 주체는 스크립트다.** `[계산]` 값은 `scripts/lookup_workplace.py`가 계산해 출력하고
리포트는 인용만 한다. 리포트 작성 중에 다시 계산하면 같은 회사를 두 번 조회했을 때
값이 흔들려서, 이 등급이 약속하는 검증 가능성 자체가 깨진다.

## 리포트 데이터 → 등급 매핑

| 데이터 / 항목 | 등급 | 비고 |
|---|---|---|
| 사업자 상태 (계속/휴업/폐업) | `[확정]` | 국세청 API 원본 |
| 국민연금 사업장 가입/탈퇴 상태 | `[확정]` | 국민연금 API 원본 |
| 임금체불 명단 등재 여부 | `[확정]` | 고용노동부 공개 기록 (부재는 "없음"이 아님, `[미확인]`으로 병기) |
| 업종 분류 (`vldtVlKrnNm`) | `[확정]` | 국민연금 API 원본 |
| DART 재무제표 수치 | `[확정]` | 공시 원본 (있을 때) |
| 연환산 이직률 | `[계산]` | `lssJnngpCnt` 합계 / **현재** 가입자수. 10명 미만이면 비율 억제 |
| 1인당 추정 고지금액 (연봉 협상 기준선) | `[계산]` | `crrmmNtcAmt / jnngpCnt`. `--detail` 출력 인용 |
| 신규 입사자 추이 (채용 활발도) | `[계산]` | `nwAcqzrCnt` 합계. 집계식 노출 |
| 1인당 고지금액 **추이** | `[미확인]` | 시계열이 API에 없어 산출 불가 |
| 부채비율·유동비율 등 재무 지표 | `[계산]` | DART 수치 기반. 계산식 노출 |
| 런웨이 압박 등 간접 신호 | `[추정]` | 마지막 투자 경과 기간 등. 반증 가능 |
| 회사 주장 규모 vs 실제 가입자 괴리 해석 | `[추정]` | 확정 데이터(가입자수)는 `[확정]`, 그로부터의 "과장" 판단은 `[추정]` |
| 잡플래닛·블라인드 리뷰, 커뮤니티 후기 | `[전언]` | 출처 수 명시. 점수화 금지 |
| 급여 지연·논란 등 커뮤니티 제보 | `[전언]` | 독립 출처 건수 명시 |
| 매출 규모 (비상장·공시 의무 없음) | `[미확인]` | 데이터 없음 |
| 현금흐름·런웨이 실측치 | `[미확인]` | 비공개 |

한 문장이 확정 데이터와 그로부터의 해석을 함께 담으면, 문장을 쪼개
확정 부분은 `[확정]`, 해석 부분은 `[추정]`으로 각각 라벨한다.

## 강제 규칙

리포트 최종 출력의 **모든 주장 문장은 위 5종 라벨 중 하나로 시작하거나 끝난다.**
이 규칙은 특정 섹션에 한정되지 않고 모든 리포트 섹션에 균일하게 적용된다
(한 화면 요약, 안전한가, 월급 안 밀리나, 사람이 나가나, 도메인, 채용, 평판, 확인 못 한 것 전부).

- `[계산]` 항목은 계산식을 같은 문장에 노출한다.
- `[전언]` 항목은 출처 건수를 같은 문장에 노출한다.
- 라벨을 붙일 수 없는 문장은 주장이 아니라 서술(설명·안내)이며, 리포트 본문 판단 근거로 쓰지 않는다.
