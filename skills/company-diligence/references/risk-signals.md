# 리스크 신호 판정 기준

기업 실사에서 사용하는 위험 신호의 상세 정의와 판정 규칙.

---

## 판정 철학

**합산하지 않는다. 최악 항목이 지배한다.**

일반적인 스코어링은 여러 항목에 점수를 매겨 평균을 낸다.
이 방식은 여기서 위험하다. 급여가 밀리는 회사는 복지가 아무리 좋아도 가면 안 되기 때문이다.
평균을 내면 치명적 결함이 좋은 항목에 희석되어 사라진다.

따라서 판정은 다음 순서를 따른다.

1. **차단 신호(blocking signal)** 가 하나라도 있으면 즉시 RED. 다른 항목을 보지 않는다.
2. 차단 신호가 없으면 **경고 신호(warning signal)** 를 센다. 3개 이상이면 AMBER.
3. 경고 신호가 2개 이하이고 검증 데이터가 충분하면 GREEN.
4. 검증할 데이터 자체가 없으면 UNKNOWN. GREEN으로 승격하지 않는다.

---

## Tier 1. 차단 신호 (하나라도 해당하면 RED)

| 신호 | 확인 방법 | 왜 치명적인가 |
|---|---|---|
| 사업자 상태가 폐업 | 국세청 API | 법인이 존재하지 않음 |
| 사업자 상태가 휴업 | 국세청 API | 영업 중단 상태. 급여 지급 주체가 멈춰 있음 |
| 국민연금 사업장 탈퇴 | 국민연금 API | 사실상 폐업·휴업. 국세청 조회로 교차확인 후 확정 |
| 임금체불 사업주 명단 등재 | 고용노동부 | 체불이 행정적으로 확정된 상태 |
| 감사의견 부적정 / 의견거절 | DART 감사보고서 | 회계 신뢰성 자체가 부정됨. 상장폐지 사유 |
| 완전자본잠식 | DART 재무제표 (자본총계 < 0) | 부채가 자산을 초과. 청산 시 남는 것이 없음 |
| 회생·파산 절차 진행 | 뉴스, 법원 공고 | 진행 중이면 신규 채용 자체가 비정상 |
| 최근 1년 내 급여지연 제보 2건 이상 (독립 출처) | 커뮤니티, 뉴스 | 명단 등재 전 단계의 실질 체불 |

RED 판정 시 리포트 문구:
> 지원 보류를 권고합니다. 진행하시려면 근로계약서 서면 교부, 급여 지급일 명시,
> 최근 6개월 급여 지급 이력을 입사 전에 반드시 확인하십시오.

## Tier 2. 경고 신호 (3개 이상이면 AMBER)

### 재무 계열
- 부채비율 200% 초과, 또는 전년 대비 100%p 이상 급증
- 매출 2년 연속 감소
- 영업손실 2년 연속 + 현금성자산 동반 감소
- 유동비율 100% 미만
- 전환사채·신주인수권부사채 반복 발행
- 감사인 교체가 2년 내 2회 이상
- 정정공시 반복

### 자금 계열 (비상장 스타트업용)
- 마지막 투자 유치로부터 18개월 이상 경과 + 후속 라운드 없음
- 투자 유치 규모 대비 인원이 과다 (인건비 소진 속도 과속)
- 매출 없이 정부 R&D 과제로만 운영되는 구조
- 브릿지 라운드가 반복됨 (다운라운드 회피 신호일 수 있음)

### 고용 계열
- 국민연금 가입자 수 지속 감소 (`lookup_workplace.py --trend {seq}` 로 확인. 가장 객관적인 고용 신호)
- 회사가 밝힌 인원 규모와 국민연금 가입자 수의 큰 괴리 (`--detail {seq}`)
- 링크드인 재직자 수 감소
- 핵심 직군(개발·영업 리드급) 동시 이탈 흔적
- 동일 포지션 공고가 3개월 이상 계속 열려 있음
- 재직 기간 중앙값이 1년 미만이라는 리뷰 언급 반복

### 운영 계열
- 서비스 앱 마지막 업데이트가 6개월 이상 전
- 기술블로그·공식 채널이 1년 이상 방치
- 오피스 축소 이전
- 주력 서비스 종료 공지 이력

### 지배구조 계열
- 대표이사가 2년 내 2회 이상 변경
- 사명 변경 이력 (특히 부정 이슈 직후)
- 최대주주 변경
- 소송·분쟁 뉴스 다수

## Tier 3. 참고 신호 (단독으로는 판정에 쓰지 않음)

- 연봉이 시장 대비 낮음: 재무 여력 부족일 수도, 단순 정책일 수도 있음
- 리뷰 평점이 낮음: 표본 편향 심함. 퇴사자가 주로 작성
- 야근이 많다는 언급: 리스크가 아니라 근무 조건 이슈. 별도 섹션으로 분리
- 복지가 부족: 재무 리스크와 직결되지 않음
- 사무실이 작음: 초기 스타트업의 정상 상태

이 항목들은 리포트의 "근무 조건 참고" 섹션에 넣고, 리스크 판정에서는 제외한다.
리스크 판정에 감정적 요소가 섞이면 신뢰도가 떨어진다.

## 신호 해석 시 흔한 오판

### 오판 1. 데이터 없음을 안전으로 해석
가장 흔하고 가장 위험한 오류.
비상장 소기업은 DART에도 없고 뉴스에도 없고 리뷰도 없다.
이것은 "문제가 없다"가 아니라 "확인할 수 없다"이다. UNKNOWN으로 처리한다.

### 오판 2. 적자를 곧바로 위험으로 해석
투자를 받은 스타트업은 계획된 적자를 낸다.
적자 자체보다 **적자 + 후속 투자 부재 + 런웨이 소진 구간**의 조합이 위험하다.
성장 단계 기업에 대기업 재무 잣대를 그대로 대면 전부 RED가 된다.

### 오판 3. 오래된 정보를 현재로 착각
3년 전 임금체불 뉴스가 있는데 그 사이 경영진이 교체되고 투자를 받았다면 상황이 다르다.
모든 신호에 시점을 기록하고, 3년 이상 지난 것은 "과거 이력" 섹션으로 분리한다.

### 오판 4. 단일 커뮤니티 글을 사실로 확정
독립적인 출처 2건 이상에서 같은 주장이 나올 때만 신호로 센다.
같은 글이 여러 사이트에 퍼진 것은 1건으로 센다.

### 오판 5. 모회사와 계약 법인을 혼동
공고는 유명한 모회사 이름으로 올라오지만 실제 계약은 자회사·용역사와 하는 경우가 있다.
급여 지급 주체는 계약 법인이므로, 실사 대상은 반드시 계약 법인이어야 한다.

## 신호별 면접 검증 질문 매핑

| 점등된 신호 | 면접에서 물을 질문 |
|---|---|
| 재무 검증 불가 | "현재 런웨이가 어느 정도이고 다음 라운드 계획이 있는지 궁금합니다" |
| 마지막 투자 18개월 경과 | "최근 투자 유치 이후 사업 지표가 어떻게 변했는지 여쭤봐도 될까요" |
| 인원 감소 흔적 | "최근 1년간 팀 규모 변화가 어땠는지 궁금합니다" |
| 동일 공고 장기 게시 | "이 포지션이 신설인지 충원인지, 충원이면 이전 담당자의 이동 사유가 궁금합니다" |
| 급여 관련 우려 | "급여 지급일이 언제인지, 지연된 사례가 있었는지 확인하고 싶습니다" |
| 매출 구조 불투명 | "주요 매출처 구성과 특정 고객사 의존도가 어느 정도인지 궁금합니다" |
| 대표 교체 이력 | "최근 경영진 변화가 조직 방향에 어떤 영향을 줬는지 궁금합니다" |
| 서비스 업데이트 정체 | "현재 제품 로드맵에서 가장 우선순위 높은 과제가 무엇인지 궁금합니다" |

질문은 추궁이 아니라 관심 표현으로 읽히도록 다듬는다.
지원자가 실제로 입 밖에 낼 수 있어야 의미가 있다.
