# 추상 문구 대조 사전

채용공고에 자주 등장하는 추상적 표현과, 그것이 실제로 가리킬 수 있는 업무.

**주의: 이 사전은 가설 생성용이다.** 여기 적힌 해석을 그대로 결론으로 쓰지 않는다.
사전으로 가설을 만들고, `inference-playbook.md` 의 방법 A~D 로 검증한 뒤에 리포트에 넣는다.
검증 없이 사전만으로 단정하면 편견을 분석이라고 파는 셈이 된다.

---

## 업무 관련

| 공고 문구 | 가능한 실제 의미 | 검증 방법 |
|---|---|---|
| 데이터 기반 의사결정 지원 | 대시보드 구축 / 지표 정의 / 애드혹 분석 대응 중 하나 이상 | 타사 공고 대조, 요구 도구 확인 |
| 서비스 안정성 향상 | 장애 대응, 모니터링 구축, 성능 튜닝 | 온콜 언급 여부, SRE 직군 유무 |
| 신규 서비스 개발 | 0에서 1. 기획 변경 잦음 | 같은 팀 동시 채용 직군 확인 |
| 레거시 시스템 개선 | 마이그레이션. 문서 없는 코드 해독 | 병기된 스택 확인 |
| 유관 부서와의 협업 | 조율 업무 비중 큼. 이해관계자 관리 | 조직 규모, 매트릭스 구조 여부 |
| 프로세스 개선 | 기존 프로세스가 문제라는 뜻 | 리뷰에서 프로세스 언급 확인 |
| 업무 자동화 | 수작업이 많다는 뜻 | 팀 규모 대비 업무 범위 |
| 고객 목소리 반영 | CS 대응 또는 VOC 분석 업무 포함 가능 | 프로덕트 리뷰, CS 조직 유무 |
| 글로벌 서비스 대응 | 시차 대응, 다국어, 현지 규제 | 해외 법인·해외 매출 실체 확인 |
| 전사 프로젝트 리딩 | 권한 없이 책임만 질 위험 | 직급, 보고 라인 확인 |

## 인재상 관련

| 공고 문구 | 가능한 실제 의미 | 검증 방법 |
|---|---|---|
| 빠르게 변화하는 환경 | 방향 전환이 잦음. 문서화 부족 가능 | 리뷰의 반복 키워드, 조직 개편 이력 |
| 멀티태스킹 가능하신 분 | 1인 다역. 인원 부족 | 팀 규모, 업무 범위 폭 |
| 오너십을 가지고 | 자율성 크거나, 지원 없이 혼자 감당 | 팀 구성, 시니어 유무 |
| 능동적으로 | 지시가 구체적이지 않음 | 신설 여부 |
| 열정적인 | 업무 강도 높을 수 있음 | 리뷰, 근무시간 언급 |
| 스타트업 마인드 | 체계 부재를 감수하라는 뜻일 수 있음 | 회사 단계, 인원 규모 |
| 대표님과 직접 소통 | 소규모. 의사결정 빠르나 변동성 큼 | 인원 규모 |
| 함께 성장할 | 교육 체계 유무를 확인해야 함 | 온보딩 언급, 주니어 비율 |

## 조건 관련

| 공고 문구 | 확인해야 할 것 |
|---|---|
| 경력 무관 | 실제로는 경력 선호일 수 있음. 우대사항 확인 |
| 협의 후 결정 (연봉) | 국내 관행. 신호로 세지 않음 |
| 수습 기간 3개월 | 정상. 단 수습 기간 급여 차등 여부 확인 |
| 계약직(정규직 전환 가능) | 전환율을 반드시 물어야 함 |
| 파견/도급 | 계약 법인이 다름. company-diligence 대상 전환 |
| 유연근무제 | 코어타임 존재 여부, 실제 사용률 |
| 재택 가능 | 주 몇 회인지, 팀 재량인지 |
| 스톡옵션 제공 | 행사가, 베스팅 조건, 회사 단계에 따라 가치가 0일 수 있음 |

## 프로덕트·비즈니스 관련

| 공고 문구 | 가능한 실제 의미 |
|---|---|
| 시장을 선도하는 | 자체 정의한 좁은 시장에서 1위일 수 있음 |
| 빠른 성장 | 무엇이 성장했는지 확인. 매출인지 유저인지 채용인지 |
| 업계 최초 | 마케팅 문구일 가능성. 근거 확인 |
| 다양한 도전 | 업무 범위가 확정되지 않음 |
| 안정적인 사업 기반 | 성장이 정체되었다는 뜻일 수도 있음 |

---

## 사용 규칙

1. 이 표는 **질문 목록을 만드는 용도**다. 결론이 아니다
2. 하나의 문구에 여러 해석이 가능하면 모두 열거하고, 어느 쪽인지 판별할 근거를 찾는다
3. 근거를 못 찾으면 "확인 불가"로 두고 면접 질문으로 전환한다
4. 부정적 해석만 골라 쓰지 않는다. "빠르게 변화하는 환경"이 실제로 좋은 학습 환경인 회사도 많다
5. 리포트에는 사전 인용이 아니라 **검증된 결과**만 쓴다
